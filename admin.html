قبل النشر

النشر النهائي يتم من خلال حساب GitHub الذي يملك الموقع. لا توجد كلمة مرور داخل هذه الصفحة؛ صلاحية التعديل والحفظ يحميها GitHub، لذلك لا يستطيع الزوار نشر خطب أو تغييرها من الموقع.

الخطب التي جهزتها

يمكنك إضافة أكثر من خطبة، أو حذف خطبة من القائمة قبل النشر.

لم تضف خطبًا بعد.

خطوة النشر على الموقع

  1. اضغط «تجهيز ملف النشر»، ثم «نسخ البيانات».
  2. افتح ملف الخطب في GitHub من الزر التالي وسجّل الدخول بحساب مالك الموقع.
  3. استبدل محتوى الملف بالبيانات المنسوخة، ثم اضغط Commit changes لحفظ النشر.
  4. بعد دقائق، ستظهر الخطب تلقائيًا في قسم «خطب الجمعة» بالموقع.
