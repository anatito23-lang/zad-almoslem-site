# نِداء | Nidaa
تطبيق أندرويد مستقل لمواقيت الصلاة والأذان.

## البناء
يتطلب JDK 17 وAndroid SDK 35 وGradle 8.9:
`gradle assembleDebug`

ملف APK الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

## الحالة الحالية
- هيكل أندرويد أصلي مستقل.
- واجهة عربية RTL بهوية كحلي وذهبي.
- حساب محلي للمواقيت بطريقة الهيئة المصرية العامة للمساحة باستخدام مكتبة Adhan.
- الصفحات الأساسية مبدئية؛ الموقع والأذان والتنبيهات والبوصلة ما زالت مراحل تطوير لاحقة.
